# IPaper 2.0 Product Blueprint

## Vision

Build a professional AI-powered Research Paper Management Platform for students, researchers, professors, and academic institutions.

## Mission

Help users upload, summarize, organize, and collaborate on research papers using AI.

## Target Users

* Students
* Researchers
* Professors
* Universities

## Existing Features

* User Registration
* User Login
* Admin Login
* PDF Upload
* AI Summarization
* Summary Export
* Community Forum
* Media Slider
* Video Showcase
* User Reviews
* PostgreSQL Database

## Planned Features

* Personal Research Library
* AI Chat with Uploaded Paper
* Citation Generator
* Reading Progress
* Collections & Folders
* Search & Filters
* Admin Analytics
* Mobile Responsive UI
* Dark Mode

## Development Rule

Every change must keep the application working.
